False alarms: 0/43 clean samples touched.

Known misses (5):

- miss-bare-token: a bare TOKEN= with a short value (under 6 characters) is not matched; longer values after TOKEN-like names are redacted as env-secret-short
- miss-base64: base64 of a key (the model could decode it)
- miss-spaced: a key split by spaces
- miss-prose-password: a password in prose with no label shape
- miss-short-label: values shorter than the minimum length of every detector

Known false alarms (2):

- code-python: an assignment such as `password = getpass.getpass(...)` has the shape of `password=<value>` (postgres-password)
- md5sum-output: md5sum output: a bare 32-hex value followed by a space has the exact shape of a Twilio auth token
