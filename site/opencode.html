ai-hooks for opencode: block commands that print secrets

Status: verified on opencode 2.2.7 in a real session: docker inspect web was refused with the ai-hooks message, and a shell command that printed a fake AWS key came back redacted.

Setup

ai-hooks install opencode            # writes ~/.config/opencode/plugins/ai-hooks.js
ai-hooks install opencode --project   # or .opencode/plugins/ai-hooks.js in this project
ai-hooks uninstall opencode

The plugin uses opencode's server plugin API: a tool.execute.before hook that throws to block, and a tool.execute.after hook that rewrites the result. It starts the binary with arguments (no shell). The shell tool is named shell in opencode 2.x and bash in 1.x; the plugin handles both.

See also: MCP, any shell.

ai-hooks is Apache-2.0. Source · Built and used daily at KOA Labs.
