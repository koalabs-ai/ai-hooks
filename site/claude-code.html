ai-hooks for Claude Code: stop it printing secrets

Status: verified on Claude Code 2.1.325: a real session was blocked from running journalctl -u app, and the output of a harmless command was rewritten before the model saw it.

How to prevent Claude Code from printing secrets

Add both hooks to ~/.claude/settings.json. ai-hooks config claude prints this with your binary path.

{
  "hooks": {
    "PreToolUse":  [{"matcher": "Bash", "hooks": [{"type": "command", "command": "ai-hooks hook claude", "timeout": 10}]}],
    "PostToolUse": [{"matcher": "Bash", "hooks": [{"type": "command", "command": "ai-hooks hook claude", "timeout": 10}]}]
  }
}

A Claude Code PreToolUse hook example

The hook reads the payload on standard input and, for a risky command, answers with permissionDecision: deny and a reason. The model reads the reason and re-runs the command through the redactor.

echo '{"hook_event_name":"PreToolUse","tool_name":"Bash","tool_input":{"command":"journalctl -u app"}}' | ai-hooks hook claude
{"hookSpecificOutput":{"hookEventName":"PreToolUse","permissionDecision":"deny","permissionDecisionReason":"ai-hooks [journalctl-unit]: ..."}}

PostToolUse: mask what the model sees

For PostToolUse the hook walks every string in tool_response and, if anything was redacted, returns the same object as updatedToolOutput. When nothing was redacted it prints nothing and costs about 11 ms.

As a plugin

The repository is also a one-plugin marketplace: claude plugin marketplace add koalabs-ai/ai-hooks, then claude plugin install ai-hooks@ai-hooks. The binary must be on your PATH.
