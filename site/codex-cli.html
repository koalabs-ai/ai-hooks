ai-hooks for Codex CLI (untested)

Status: implemented from the vendor docs, not run. The vendor documents a hook mechanism, but ai-hooks has not been run inside this harness, so no support is claimed. The pipe mode below works anywhere, and it is the verified fallback. If you try it, an issue or pull request saying what happened is the most useful thing you can send.

What the vendor documents

Codex CLI documents PreToolUse and PostToolUse command hooks for its shell tool (a hooks.json or a [hooks] table in config.toml, version 0.124 or newer, at the time of writing). The payload looks like Claude Code's. ai-hooks install codex writes the PreToolUse hook (and ai-hooks hook codex answers it); output rewriting would use a block decision that replaces the result with the redacted text. Written from the documentation; not run, because Codex is not installed on the machine this was built on.

What works today

ai-hooks guard -- 'journalctl -u app'        # exit 2 with the reason on stderr
some-command 2>&1 | ai-hooks redact
ai-hooks exec -- some-command

Run the agent's shell commands through ai-hooks exec (for example with a shell wrapper or an instruction in AGENTS.md) to get both halves with any harness.
