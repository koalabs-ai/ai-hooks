ai-hooks for Cursor (untested)

Status: implemented from the vendor docs, not run. The vendor documents a hook mechanism, but ai-hooks has not been run inside this harness, so no support is claimed. The pipe mode below works anywhere, and it is the verified fallback. If you try it, an issue or pull request saying what happened is the most useful thing you can send.

What the vendor documents

Cursor documents beforeShellExecution (can allow or deny) and afterShellExecution (observe only), configured in hooks.json. ai-hooks install cursor writes the guard half; output redaction is not possible in Cursor's hooks. Written from the documentation; not run.

What works today

ai-hooks guard -- 'cat .env'; echo $?     # 2
ai-hooks exec -- some-command
ai-hooks is Apache-2.0. Source · Built and used daily at KOA Labs.
