ai-hooks for any shell: redact secrets from terminal output

Status: verified. This is the mode the tests and the demo use.

Redact secrets from terminal output

kubectl logs deploy/api 2>&1 | ai-hooks redact
docker compose logs | ai-hooks redact --stream
some-cmd | ai-hooks redact --json > /dev/null     # {"redacted":2,"by_type":{...}}: counts only

Guard, then run, then redact

ai-hooks guard -- 'cat .env'        # exit 2, one line on stderr
ai-hooks exec -- cat .env           # guard, run, redact the output, keep the exit code

Your own rules

Add rules, disable defaults or allow patterns in ~/.config/ai-hooks/rules.json. ai-hooks rules prints the defaults. See the design note.

ai-hooks is Apache-2.0. Source · Built and used daily at KOA Labs.
