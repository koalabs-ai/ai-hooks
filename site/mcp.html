ai-hooks as an MCP server: guard, redact, scan and safe_run tools

Status: verified with Claude Code's MCP client: the redact, guard and safe_run tools were called by a real session and their results read back.

Register the server

claude mcp add ai-hooks -- ai-hooks mcp          # Claude Code
# any other MCP client: command ai-hooks, args [mcp], transport stdio

Tools

  • guard: is this command safe to run? Returns blocked, the rule and a one-line instruction.
  • redact: mask secret-shaped strings in text; returns the redacted text and counts by type.
  • scan: list secret-shaped values in text (type, fingerprint, line; never the values).
  • safe_run: run a command after the guard allows it, with its output redacted, time-limited and size-capped.

safe_run runs commands as the user who started the server: it is not a sandbox. Turn it off with ai-hooks mcp --no-run or restrict it with --allow-run REGEX (commands with shell metacharacters are then refused). Works for Cline, Continue, Amp, Zed and other MCP clients; they are not tested here.

ai-hooks is Apache-2.0. Source · Built and used daily at KOA Labs.
