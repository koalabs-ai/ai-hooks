ai-hooks for Kimi Code: block commands that print secrets

Status: verified on Kimi Code 2.6.1 in a real session (guard only). Kimi hooks can block a tool call but cannot rewrite its output, so the redaction half is not available there; use ai-hooks exec or a pipe.

Setup

Add to ~/.kimi-code/config.toml (ai-hooks config kimi prints it):

[[hooks]]
event = "PreToolUse"
matcher = "Bash"
command = "ai-hooks hook kimi"
timeout = 10

When Kimi tries journalctl -u app the tool result it gets back is the ai-hooks reason, and it quoted it to the user in the verification run. Kimi reads hooks only from the user-level config, never from a project.

See also: any shell.
